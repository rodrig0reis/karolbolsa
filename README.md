# Karol Bolsas - Vitrine e E-commerce

Projeto desenvolvido para a loja **Karol Bolsas**, focada em bolsas femininas e acessórios, com uma identidade visual moderna, elegante e conversiva.

## Fase Atual: Fase 2 (Base do Projeto)
O projeto inicial em Next.js (App Router) foi gerado e configurado com Tailwind CSS e Shadcn UI. A página inicial mockada e o layout base estão prontos.

## Tecnologias
- **Next.js 15 (App Router)**
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Shadcn UI**

## Como rodar localmente

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Rode o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

3. **Acesse no navegador:**
   Abra `http://localhost:3000`

## Estrutura Atual
- `src/app/page.tsx`: Página inicial mockada.
- `src/app/layout.tsx`: Layout base contendo Header e Footer.
- `src/app/globals.css`: Variáveis CSS com a paleta de cores (Nude, Rose, Marrom).
- `src/components/public/`: Componentes da loja (Header, Footer).
- `src/components/ui/`: Componentes base (Shadcn UI).
